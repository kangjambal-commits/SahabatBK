SahabatBK v3.0 RC9 — Mobile Horizontal Tables

Basis: v3.0 RC8.

Perubahan:
- Sistem tabel mobile berbentuk kartu RC8 dihapus.
- Semua tabel tetap menggunakan struktur tabel seperti desktop.
- Pada layar <=700px, tabel dapat digeser horizontal kanan/kiri.
- Header tabel tetap terlihat sebagai header kolom.
- Kolom dan tombol aksi diberi lebar minimum agar teks tidak pecah vertikal.
- Manajemen Pengguna, Penugasan Konselor, Asesmen, Data Siswa, Bakat & Minat,
  Konseling, Tindak Lanjut, Karier & Studi, Laporan, dan tabel siswa binaan mengikuti pola ini.
- Navigasi hamburger RC7 tetap dipertahankan.
- Desktop tidak diubah.
- Tidak ada perubahan database, SQL, RLS, atau Edge Function.

Instalasi lokal:
1. Extract ZIP.
2. Salin seluruh isi ke D:\\SahabatBK dan Replace file lama.
3. Ctrl+F5.

GitHub Pages:
Upload/replace minimal index.html, style.css, dan app.js dari RC9 pada repository SahabatBK.
