SahabatBK v3.0 RC5 — Optical Icon Centering

Basis: v3.0 RC4.
Perubahan hanya pada CSS dashboard:
- SVG ikon statistik dipusatkan absolut pada lingkaran (50%/50%).
- SVG ikon Akses Cepat dipusatkan absolut pada lingkaran.
- Stroke ikon dipaksa putih agar konsisten pada semua browser.
- Ikon, teks, dan panah Akses Cepat diselaraskan pada garis tengah.
- Tidak ada perubahan database, RLS, Supabase, session, maupun logika modul.

Instalasi:
1. Backup versi sebelumnya.
2. Ganti index.html, style.css, app.js (dan app.js.txt bila digunakan) dengan paket ini.
3. Buka aplikasi dan tekan Ctrl+F5 satu kali.
4. Uji Dashboard sebagai Admin dan Konselor.

Tidak ada SQL yang perlu dijalankan.
