SahabatBK v2.9.2 - Responsive Sidebar
Basis: v2.9.1 stabil.

Perubahan hanya pada tata letak sidebar:
- Badge Admin Sekolah/Konselor center horizontal dan vertikal.
- Spacing logo, role, menu, dan tombol Keluar dibuat konsisten.
- Sidebar desktop memakai tinggi viewport dinamis (100dvh).
- Pada layar pendek, menu menggunakan scroll internal agar Laporan/Pengaturan tidak tertutup tombol Keluar.
- Optimasi desktop: 1280x720, 1366x768, 1536x864, 1920x1080.
- Optimasi mobile mulai lebar viewport 360px.
- Tidak ada perubahan database, RLS, session role, konseling, penugasan, atau serah terima.

Instalasi:
1. Backup versi v2.9.1.
2. Ganti file aplikasi dengan paket ini.
3. Buka index.html lalu Ctrl+F5 satu kali.
4. Uji Admin dan Konselor pada tinggi layar berbeda.
